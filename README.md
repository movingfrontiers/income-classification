# Income Classification Projections

Underlying data for "The Great Income Inversion", published on Moving Frontiers.

## Files

- `income-classification-through-2050.xlsx` — the full workbook, seven sheets,
  with the projection driven by formulas off a single Assumptions sheet.
- `csv/panel-long.csv` — tidy long format, one row per economy-year, for direct
  use in Python or R.
- `csv/` — one CSV per sheet of the workbook.

218 economies classified in 2025, of which 197 are projected forward and 21 are
held at their 2025 class.

## Sources

World Bank OGHIST (1 July 2026) and WDI GNI per capita, Atlas method, July 2026 vintage.
